เว็บวันครบรอบ เก็ต 💗 บิบิ้

ไฟล์:
- index.html: หน้าเว็บ
- server.js: เซิร์ฟเวอร์สำหรับ Railway
- package.json: คำสั่งติดตั้ง/เริ่มเว็บ

วิธีใช้:
1. แตกไฟล์ ZIP
2. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์ทั้ง 4 ไฟล์ไว้ที่ root ของ repository
3. เข้า Railway > New Project > Deploy from GitHub Repo
4. เลือก repository นี้ แล้ว Deploy
5. เมื่อ Deploy เสร็จ เข้า Service > Settings > Networking > Generate Domain
6. เปิดลิงก์ที่ได้เพื่อตรวจสอบเว็บ

หมายเหตุ: รูปที่เลือกในช่องรูปคู่เป็นการแสดงผลในเบราว์เซอร์เครื่องนั้นเท่านั้น
ถ้าต้องการให้แฟนเห็นรูป ต้องเพิ่มไฟล์รูปเข้า repository และแก้หน้าเว็บให้ใช้รูปเหล่านั้นก่อน Deploy
